Tibetan Quiz — PWA package

Upload these files to the ROOT of one GitHub repository:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

Important: vocabulary is stored in the browser/PWA localStorage on the device.
It is NOT included in these source files unless you manually add it.
Use the app's Backup function to keep a separate backup of your vocabulary.
